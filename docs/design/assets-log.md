# 字型（自行託管，任務 R12-2）

網站不再向 Google Fonts 請求任何檔案；字型隨網站一起發布（`dist/_astro/`）。字型全部是 **SIL Open Font License 1.1**，允許隨網站散布與子集化。OFL 只禁止修改版使用「保留字型名稱」：Noto Sans TC 的授權保留的是「Source」（源自 Adobe 思源黑體），Noto Serif TC 與 Alegreya 沒有保留名稱；子集只沿用原本的 Noto 名稱，沒有用到「Source」。授權全文隨網站發布在 `/fonts/OFL-NotoSansTC.txt`、`OFL-NotoSerifTC.txt`、`OFL-Alegreya.txt`、`OFL-AlegreyaSans.txt`（建置時由 `scripts/font-subset.mjs` 的 `fontLicenses` 從各套件的 `LICENSE_FONT`／`LICENSE` 複製到 `dist/fonts/`）。中文子集另外在字型的 name table 保留版權（ID 0）、商標（ID 7）、廠商網址（ID 11）、授權說明（ID 13）與授權網址（ID 14），單元測試會檢查；拉丁字型的 fontsource 切片本來就保留 ID 14。

| 字型 | 套件（版本） | 載入字重 | 用途 |
|---|---|---|---|
| Alegreya（Juan Pablo del Peral／Huerta Tipográfica） | `@fontsource/alegreya` 5.3.0 | 500、700、500 italic | `--font-title` 的拉丁字母 |

| Noto Serif TC（Google） | 建置：`@expo-google-fonts/noto-serif-tc` 0.4.5；開發：`@fontsource/noto-serif-tc` 5.3.1 | 700 | `--font-title` 的中文 |

- **依語言分開**：中文頁載 `src/styles/fonts-zh.css`（拉丁＋中文），英文頁載 `fonts-en.css`（只有 Alegreya 系列；英文頁上少數中文字，例如語言連結「中文」、術語提示框的中文名，用系統的中文字型）。
- **中文字型子集（R12 字型子集）**：每次正式建置時，`scripts/font-subset.mjs` 收集 `src/` 底下所有文字檔用到、U+00A0 以上的字元（事件、註、glossary、people、地點、介面字串、圖說…，目前 1,487 個），用 `subset-font` 2.9.0（harfbuzz 的 WebAssembly 版，BSD-3-Clause；Windows、macOS、CI 都能跑，不需要 Python 或原生工具）把三個中文字面各裁成一個 woff2：Noto Sans TC 400 約 224 KB、700 約 230 KB、Noto Serif TC 700 約 301 KB。`fonts-zh.css` 裡 fontsource 的 Noto 切片在建置時全部換成這三條 `@font-face`（`unicode-range` 正好是子集的字）。子集檔快取在 `node_modules/.cache/chronicle-fonts/`，檔名含文字與原字型的雜湊：內容沒變就沿用，新增任何字就重算（每個字面約 1 秒）。開發伺服器（`astro dev`）沿用 fontsource 切片，邊寫邊看時新加的字不會掉回系統字型。
- **拉丁字型**：沿用 fontsource 依 latin／latin-ext／cyrillic／greek／vietnamese 的切檔，瀏覽器只下載用到的那幾檔。
- **只發布 woff2**：fontsource 在每個 woff2 後面附 woff 備援；同一個 PostCSS 外掛（`fontsource-build`，設定在 `astro.config.mjs`）在建置時拿掉。建置輸出 45 個 woff2，`dist/_astro` 約 1.7 MB。

- **演進**：中文首頁字型 37 個檔、1437 KB → 7 個、645 KB；字型 CSS 590 KB（兩語共用）→ 中文 41 KB（gzip 5 KB）／英文 11.6 KB；建置的 woff2 562 → 45 個，`dist/_astro` 16 → 1.7 MB。
- **字重（decisions/round3）**：中文只留 Noto Sans TC 400／700、Noto Serif TC 700。檢查全部 CSS：中文出現在 `--font-title` 的地方（站名、事件名、小節標、紀元名、日期、名牌、區域名、路徑目前層、「¶ 註」、圖說標籤）全部是 700；`--font-body` 的中文只用 400 與 700（粗體術語）；用 500 的兩處（`.brand-sub` 英文副標、`.story-en` 英文原標）都是拉丁字，由 Alegreya 系列負責，所以畫面沒有變化。拉丁字型評估後**不刪**：Alegreya 500 是非粗體 `--font-title` 拉丁字（時間軸「‹ ›」、提示框的英文名）的字重，拿掉會變成 700；Alegreya Sans 500 只用在中文頁桌機的英文副標，拿掉會變成 400。
- **載入方式**：`src/layouts/Base.astro` 以 `media="print"` 的 `<link>` 先下載字型 CSS，等頁面 `load` 之後才改成 `media="all"`，字型這時才開始下載，不會排在程式、樣式與地圖圖檔前面（沒有 JavaScript 時由 `<noscript>` 直接套用）。`font-display: swap`，字型到之前先用備用字型顯示（使用者接受，decisions/round3）。
