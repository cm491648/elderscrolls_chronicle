## 1. 風格定位

**一句話：每則事件是帝都典藏館裡一頁裝幀過的抄本。** 參考中世紀泥金抄本的**版面規則**（朱紅標題字、青金石藍、金線、版心與邊註），但不仿舊：紙是乾淨的骨白，墨是帶藍的鐵膽墨，顏色節制。材質感由**線條、框法、字型與留白**表現，不用漸層假裝材質。

關鍵字：骨白紙、鐵膽墨、青金石、金線、朱紅標題字。

**書封與紙頁（2026-10-24 起）**：地圖與插圖已有奇幻與歷史感，介面跟上：整個網站像一本帝國圖書館的書。頁首與時間軸包在深色皮革書封裡，地圖、故事欄與浮出的面板是舊紙頁，頁尾是皮革條；分隔線、框與按鈕用同一套自繪紋飾（見第 4 節）。材質是 Codex 手繪的圖檔（`src/assets/textures/`），**仍然不用 CSS 漸層假裝材質**。不做夜間模式（decisions/es-feel-1）。

### 1.1 要避免的感覺

- 米色底＋襯線字＋陶土橘的「AI 預設復古風」、紫藍漸層、霓虹光暈、毛玻璃。
- 膠囊徽章、每張卡片都同樣圓角陰影、每個區塊都置中。
- 用漸層假裝材質（木紋、金屬、羊皮紙）。
- 複製官方遊戲介面、紋章或 Daedric／Dwemer 字母。
- **首字放大（drop cap）**：使用者明確不要。設計稿中的青金石首字方塊（`.initial`）不實作，英文頁原本的 `::first-letter` 放大也已移除。

## 4. 版面與裝飾原則

- **頁尾**：一行淡墨小字，中英各一版（`disclaimer`）：非官方粉絲網站、與 Bethesda Softworks／ZeniMax Media 無關也未獲背書、名稱與地圖圖像的版權歸屬、官方地圖經 UESP 取得（`disclaimerOfficialMap`，總稱：各圖的出處在地圖圖說逐張標示）。
- **頁首**：皮革書封（`.leather`），站名紙色（`--on-leather`）＋中文頁才有的英文小字副標；右側「搜尋與篩選」是皮革上的深底金框按鈕，語言切換是紙色純文字連結；和時間軸交界處是收尖金線（`.orule-bottom`）。頁首在時間軸之上一層（`z-index: 11`），菱形不會被黏在頂端的時間軸蓋住。
- **頁尾**（2026-10-24 起）：皮革條，上緣收尖金線（`.orule-top`），紙色小字（`--on-leather-soft`）；寬螢幕故事欄內的頁尾同樣是皮革，寬度跟欄。
- **紋飾**（`global.css`「Ornaments」一段，decisions/es-feel-spec-2）：
  - **收尖金線**：`.orule-top`／`.orule-bottom` 在元素上緣或下緣畫一條兩端收尖的 3px 金線（`::before`，`clip-path` 菱形），中央一顆 8px 菱形，外圍一圈底色、一圈金線（`::after`）。皮革上加 `.on-leather` 換成 `--gilt-on-leather`。用在頁首下緣、「¶ 註」上緣、頁尾上緣。
  - **角飾**：`.corners` 只在**左上與右下兩個對角**放金色彎角加小菱形（`::before`，兩個 SVG 背景）；不進無障礙樹、不擋點擊。用在時間軸帶外框、地圖、故事欄、搜尋與篩選面板、地圖彈出框。
  - **雙線框按鈕**：1px 金框，內縮 4px 一圈淡金線（`outline` 負 offset，不必知道底色）；鍵盤焦點時改成青金石焦點環。圓形按鈕外加第二圈金環。徽章同樣雙線，用朱紅。
  - **清單**：故事欄清單符號是金色小菱形（`::marker` 內容；不支援的瀏覽器顯示金色圓點）。紀元名前有朱紅小菱形（SVG `tspan`，`aria-hidden`）。
  - 這些 class 的 `position: relative` 用 `:where()` 寫成零權重，本來就有定位（`absolute`、`fixed`）的元素保留自己的定位。
- **材質**：`.paper` 是舊紙（`--paper` 底＋紙材質）、`.leather` 是書皮（`--leather` 底＋皮革材質），兩張都是 512px 平鋪；頁面底是紙材質正片疊底在 `--page` 上（`body` 與窄螢幕黏住的 `.sticky-head` 一致）。
- **圖版框法只有一套**：「圖版」＝ 1px 墨框，往外 4px 再一圈 1px 金線（`outline` ＋ `outline-offset`）。地圖與插圖都用這套；圖版外面的紙頁面板另用 1px 金框＋角飾。
- 面板是方角（`--radius: 2px`）。圓形只用於時間軸上的按鈕。
- 動態效果只有滑過時的小幅放大、淡入、地圖收合／展開與高度變化（0.3s），以及選事件時捲到故事開頭（平滑捲動）；「減少動態效果」時全部取消、直接切換（`global.css` 最後一段；時間軸、地圖的 `duration()` 回傳 0；`ChronicleApp.tsx` 的捲動改用 `behavior: 'auto'`）。

### 4.1 版面骨架（R12）

**寬螢幕（寬 ≥ 900px 且高 ≥ 560px）：並排檢視**（使用者決定：地圖與故事同時檢視，地圖與視窗等高）。高度不到 560px（例如手機橫放 915×412）時改用下面的上下排，頁面可捲，故事欄底部的出處與頁尾都讀得到（CSS 與 `ChronicleApp.tsx` 的 `WIDE_QUERY` 用同一個條件）。

- 頁首 › 時間軸（橫跨全寬）› 地圖。地圖高度正好是「視窗高度 − 頁首 − 時間軸」（`--map-h-wide`，最少 320px），整張看得到，不必捲頁。
- 選了事件時，地圖右側出現故事欄，寬 `clamp(400px, 34vw, 560px)`（`--story-col-w`，含左側 18px 間距）。故事欄 `.story-col` 自己捲動（`overflow-y: auto`、`overscroll-behavior: contain`），頁面本身不捲動；頁尾版權聲明放在故事欄最底下。沒有「收合地圖」。
- 版面是 `.stage` 的兩欄 grid（`.sticky-head` 在寬螢幕為 `display: contents`）：時間軸佔第一列全寬，第二列左邊地圖、右邊故事欄。開啟故事時欄寬一次到位，讓地圖用最後的尺寸框選；關閉時地圖以 0.3s 的 `grid-template-columns` 轉場展開回全寬；減少動態效果時直接切換。
- 首頁：地圖全寬、同樣到視窗底；「請在時間軸或地圖上選擇一則事件。」是地圖右上角的紙色小牌，頁尾在地圖下方（捲一點才看到）。
- 地圖圖說（`.map-cap`）改成疊在圖版左下角的紙色小條，不佔高度，也不攔滑鼠（只有連結可點）。框選時底邊預留它的高度，選取名牌也會避開它（`MapView.tsx` 的 `insets()`、`placeTags()`）。
- 鍵盤：DOM 順序是時間軸 › 地圖 › 故事欄。故事從關閉變成開啟時，焦點移到故事標題（`h2 tabindex="-1"`，不畫焦點框），方向鍵與 PageDown 就能捲故事欄；從地圖彈出框選事件時也一樣。用時間軸按鈕或方向鍵換到下一則時，焦點留在原處，新故事從故事欄頂端開始。關閉後焦點回到時間軸。

**窄螢幕（< 900px）**：維持下面的上下排與往下讀時收合地圖。


- 全寬單欄，由上而下：頁首 › **黏頂區** `.sticky-head`（時間軸＋地圖＋地圖列）› 故事 › 頁尾。頁首會捲走，時間軸以下黏在畫面頂端（`position: sticky`，`--bg` 底，有故事時下緣 1px `--line` 與淡陰影）。
- **首頁**（`/zh-tw/`、`/en/`）不選事件、不顯示故事：地圖填滿畫面剩餘高度（`--map-h-home`，由量到的頁首、時間軸、頁尾高度算出），地圖下方一行淡墨提示「請在時間軸或地圖上選擇一則事件。」。上一則停用；下一則／`→` 從第一則開始。
- **選事件**（時間軸點、地圖標記、上一則／下一則、方向鍵）：網址改成事件網址、故事出現在地圖下方，頁面平滑捲到時間軸剛好黏住的位置，故事開頭緊接在地圖下方。地圖改為 `--map-h-story`：約 56dvh，但一定在地圖下方留 `--story-peek`（150px）給故事的日期與標題（畫面矮時標題優先），上下限桌機 300～720px、< 900px 為 240～480px。實測圖版：1440×900 為 1382×449、1920×1080 為 1862×565、1280×720 為 1222×269、Pixel 7 約 382×349～394，以上直接開事件網址或從首頁點選，標題都在畫面內。事件網址直接進入時故事直接顯示。
- **關閉**：故事右上角「× 關閉」（名稱「關閉故事」）。回到首頁網址、捲回頂端，焦點移到時間軸的可聚焦點。上一頁／下一頁在故事與首頁之間切換（`history.scrollRestoration = 'manual'`，由程式決定捲動位置）。
- **地圖收合**：有故事時，往下讀超過黏住位置 48px 就把地圖收合為 0 高（`.map-wrap.is-folded`，`inert`＋收合後 `visibility: hidden`），時間軸仍在頂端；捲回頂端（8px 內）或按地圖列的「顯示地圖」展開，展開後要再往下讀 48px 才會收合。故事太短（收合後頁面就捲不過黏住位置）時不收合，避免來回彈跳。地圖列在有故事時是「顯示地圖／收合地圖」切換鈕（`aria-expanded`、`aria-controls`）。`html` 設 `overflow-anchor: none`（收合時不讓瀏覽器自動補捲動）與 `scroll-padding-top`＝黏頂區高度＋12px（聚焦、尋找時捲到的東西不會被黏頂區蓋住）。
- **故事欄**：寬上限 `--measure`（35em）加內距，置中；手機左右各 12px。

## 5. 元件樣式

### 5.1 時間軸（`.timeline`，`Timeline.tsx`／`Timeline.css`）

- **抄本帶** `.tl-scroll`：`--band` 底，上下各 1px `--gilt`。左右各 3% 淡出，但只套在主軸與事件點上（SVG `<mask>` 掛在 `.tl-faded` 群組）；紀元名與分界線不淡出，維持完整對比（WCAG 1.4.3）。
- **紀元**：分界是 1px `--gilt` 直線（60% 不透明）；紀元名朱紅 `--font-title` 13px 粗體、字距 .06em，寫在該紀元可見範圍的左上角；放不下就不寫。
- **主軸**：雙線，上方 1px `--gilt`，下方 1px `--ink`。
- **兩端留白**（第 4 期，`decisions/p4-design`、`p4-review`）：時間開始前留 32px（`PAD`，兩個點擊半徑），時間結束後留帶寬的 12%，最少 48px、最多 120px（`padEnd()`，`src/lib/timeline-view.ts`），所以 4E 201 的標記就算放到最大、平移到最右，右邊也一定有空白。主軸與淡出延伸到留白裡。
- **世紀虛線** `.tl-century`（第 4 期）：只畫在有年份的紀元，每 100 年一條；畫面上間距不到 24px 時改成每 500 年、再不夠改每 1000 年，連 1000 年都不到 24px 就不畫（`centuryLines()`，`src/lib/timeline-view.ts`）。紀元起點、終點不畫（那裡有紀元分界線）。1px `--line`、`stroke-dasharray: 3 4`，從紀元名列下方畫到最後一條軌道，放在淡出 mask 內，不標字、`aria-hidden`。
- **事件點** `.tl-dot`：青金石實心圓直徑 12px、2px `--band` 外環；滑過或鍵盤聚焦放大到約 16px、外環變金，帶上方出現紙色名牌 `.tl-chip`。
- **年份** `.tl-year`：每個點下方寫年份（`4E 171`，前兩紀元為 `DE`／`ME`；沒有年份寫「未知」／Unknown），群組寫首尾範圍（同紀元 `1E 242–700`，跨紀元 `3E 433–4E 171`，兩端相同只寫一個）。11px 淡墨、等寬數字；選取的那個改青金石粗體。放不下時不重疊：選取的先放，其餘由左到右，會和已放的標籤重疊（間距 6px 內）就不畫（`placeLabels()`，`src/lib/timeline-view.ts`），放大後自然出現更多。年份標籤本身 `aria-hidden`；每個點與群組以 `aria-describedby` 指向隱藏的年份文字，讀屏念「紅山之戰，按鈕，1E 700」（名稱仍是事件名）。
- **選取**：直徑 18px、3px 金外框，外加一圈 30px 細金環 `.tl-ring`；事件名以 `--font-title` 15px 粗體寫在年份列下方 `.tl-sel-label`（選取在群組裡時寫在群組下方）。帶高 120px。
- **群組** `.tl-cluster`：`--band` 色圓（直徑 22px），1.5px 青金石框，中間青金石數字。含選取事件的群組改 3px 金框。
- **可點範圍**：每個點與群組都有透明的 `.tl-hit`（半徑 16px，直徑 32px，`pointer-events: all`），看得到的圖形 `pointer-events: none`。中心距離小於 32px 就合併成群組，所以可點範圍不會重疊。
- **滾輪**：監聽器掛在整條 `.tl-scroll`（`passive: false`）。一般滾輪與觸控板水平滑動沿時間平移（到盡頭不攔截，讓頁面照常捲動）；`Ctrl`＋滾輪與觸控板雙指縮放以游標為中心縮放。拖曳與觸控手勢仍由 d3-zoom 處理。
- **鍵盤**：`←`／`→` 上一則／下一則（全站）；焦點在時間軸內時 `+`／`-` 縮放；事件點採 roving tabindex。
- **按鈕**：上一則／下一則是 36px 金框圓鈕、青金石箭頭；縮放鈕 30px 同樣式，放在帶下方右側。沒有選取時上一則停用、下一則從第一則開始。
- **操作提示** `.tl-hint`：帶下方一行（滾輪、Ctrl＋滾輪），可按「×」收起並記在 `localStorage`；觸控裝置（`hover: none`）不顯示。
- **窄螢幕（≤ 560px）**：抄本帶佔滿整列，上一則／縮放／下一則排在帶下方，而且一開始放大 4 倍、以選取事件為中心，只顯示附近一段。CSS（`Timeline.css`）與開場縮放（`Timeline.tsx` 的 `NARROW_QUERY`）用同一個 560px 斷點。

### 5.2 地圖（`.map-view`，`MapView.tsx`／`MapView.css`）

- **圖版** `.map-plate`：`--map-sea` 底、1px `--ink` 框、外圈 1px `--gilt`（offset 4px）。手機上外圈改為 offset 2px，貼近墨框以省空間。有點陣底圖時加 `.has-basemap`；圖版比例和地圖不同時露出的邊，用一塊 `.map-pad` 填上該圖邊緣的顏色（`map-source.ts` 每張圖的 `paper`），並和底圖套同一個濾鏡（`--map-raster-filter`，目前是 `none`），所以和圖接得起來。
- **兩個地圖版本**（`src/lib/map-source.ts`、`src/lib/map-set.ts`，P3-B）：網站只發布官方版（`official`）；自繪版（`drawn`）是官方圖必須下架時的備用（使用者試看後決定不給讀者切換，`decisions/p3-map-drop`）。建置時設 `PUBLIC_MAP_SOURCE=drawn`（或改 `src/lib/map-source-default.mjs`）才改發布自繪版：`setMapSet('drawn')` 一次換掉各層形狀（`OFFICIAL_MAPS`／`DRAWN_MAPS`）、地點位置與底圖，頁尾拿掉「官方地圖經 UESP 取得」，輸出裡的 `maps/official/` 也刪掉；正式建置則反過來刪掉 `maps/drawn/schematic/`（e2e 用自繪版建第二份網站）。

  - **自繪點陣圖**（奈恩、宇宙）：圖上沒有文字而且畫面繁複，中英文頁都用紙色名牌。被選取的地點若與所在區域同名（阿特摩拉、凡界），只留地點名牌，不重複顯示區域名牌。

### 5.3 故事面板（`.story-pane`／`.story`，`StoryPanel.tsx`／`StoryPanel.css`）

- 面板：在地圖下方置中的一頁，`--surface` 底、1px `--line` 框、`--shadow`，內距 26px 28px 32px（手機 20px 18px 26px），寬上限 `--measure`＋內距。只在選了事件時出現（見 4.1）。
- **關閉鈕** `.story-close`：右上角「× 關閉」，13px 淡墨、1px `--line` 方框、32px 高；滑過變青金石與 `--wash`。日期小標右側留 88px，不和它重疊。
- 由上而下：日期小標（朱紅、字距放寬）→ 事件名（`--font-title` 700）→ 英文原標（只在中文頁）→ 徽章列 → 正文（中段插入插圖，見第 6 節）→ 「註」→ 人物、相關作品、出處。
- **英文原標** `.story-en`：只在翻譯頁（中文頁）出現，寫在事件名正下方，`lang="en"`；`--font-title` 14px 500 斜體、`--ink-soft`（設計稿方向 A 的 `st-en`）。英文頁不加，因為英文是原始資料來源。文字取自同 id 的 `src/content/events/en/<id>.md` 的 `title`（`src/lib/data.ts` 以 `originalTitle()` 帶進 `titleEn`），中文檔不另外存英文標題。
- **徽章** `.badge`：朱紅 1px 細框方角小牌，字距 .1em（不用膠囊、不用可信度色塊）。「校對未達共識」是實心朱紅底、`--on-accent` 字，最醒目。「地點不明」以淡墨文字跟在徽章後。
- **不做首字放大**（見 1.1）。
- **註** `.story-notes`：`<details>` 預設展開（2026-10-24 使用者要求：讓讀者自己判斷要相信哪個說法），換故事時重新展開，讀者仍可自己收合；內文字級與行高和正文相同（中文 16px／1.85、英文 17px／1.65）；上方 1px 金線；摘要列至少 36px 高、整列可點，內容是朱紅「¶ 註」＋淡墨「N 則．異說與出處」＋右側箭頭（展開時朝下、收合時朝右）。內容若是有序清單，中文頁用朱紅「一、二、三」編號、英文頁用數字；每則開頭的粗體分類字為青金石。
- **人物／作品／出處**：13px 朱紅小標，上方 1px `--line` 細線，清單符號金色。

### 5.4 術語與提示框（`.term`／`.term-tip`，`TermTooltip.tsx`）

- 術語：墨色粗體＋青金石點狀底線（1.5px，offset 5px）；滑過或開啟（`.is-open`）時襯 `--wash`。中文頁第一次出現時英文名放在 `.term-en`（400、淡墨、0.9em）。
- 提示框：`role="tooltip"`，紙色卡片、1px `--line` 框、上緣 3px 金線、`--shadow-pop`，寬度依內容、最多 290px。名稱用 `--font-title` 18px 青金石；另一語言名稱 13px 淡墨（英文名斜體）；簡介 13.5px。
- 行為：
  - 滑過、聚焦或點擊開啟；移開、失焦、`Esc`、點別處關閉。手機點一下開啟。
  - 以 portal 掛在 `<body>`，**不在**故事的 `aria-live` 區域裡；開啟時才在術語上設 `aria-describedby`。
  - 滑鼠可以從術語移進提示框而不關閉（離開後 200ms 才關，期間移入就取消），符合 WCAG 1.4.13。
  - 頁面捲動時關閉（提示框是 `position: fixed`，不關會錯位；故事現在是頁面的一部分，不再自己捲動）；視窗縮放（手機網址列收合、虛擬鍵盤）只重新定位，不關閉。

### 5.5 手機版（< 900px）

- 上下排（見 4.1「窄螢幕」），**沒有底部抽屜**（R12 移除，`src/lib/sheet.ts` 一併刪除）。
- 全站有兩個寬度斷點：**899px** 只調整間距（左右 12px、頁首不顯示英文副標、故事面板內距較小、有故事時地圖 `clamp(220px, 40dvh, 460px)`）；**560px** 只管時間軸本身的排列與開場縮放（見 5.1）。
- 往下讀故事時地圖收合，捲回頂端或按「顯示地圖」展開（寬螢幕並排時沒有收合）。
- 地圖出處說明只寫一行短版（使用者決定，decisions/acceptance2）：「地圖：Anthology · UESP」「地圖：《遺忘之都》· UESP」「地圖：《無界天際》· UESP」「地圖：本站自繪」（英文 `Map: Anthology · UESP` 等，i18n `mapCredit*Short`），不折行。完整說明仍在同一段文字裡（`.cap-long` 以視覺隱藏保留給螢幕閱讀器，短版 `aria-hidden` 並以 `title` 帶完整說明），頁尾保留完整版權聲明。寬螢幕維持疊在圖版左下角的完整說明。

### 5.6 連結、按鈕與焦點

- 連結 `--accent`，底線 offset 3–4px。
- 鍵盤焦點：2px `--accent` 外框（SVG 內的時間軸點改為在可點圓上畫 2px 青金石圈）。
- 地圖上的鍵盤焦點（區域與標記）改用**紙墨雙色環**：外側 `--surface` 寬環（區域 7px、標記 6px），內側 `--ink` 細線（區域 3px、標記 2.5px）。紙與墨位於明度的兩端，所以不論底下是點陣地圖的哪個顏色，至少有一色對比 ≥ 3 : 1（實測最低 3.88）。區域的焦點環畫在疊加層 `.region-focus`，只在 `:focus-visible` 時出現，滑鼠點擊不畫。
- 所有可點目標至少 24×24px（時間軸點 32px、地圖標記 28px、圖層與彈出框按鈕 28px 高、提示收起鈕 24px）。

### 1. 風格定位

**一句話：一份攤開在書桌上的手抄編年史。** 使用者不是在操作一個應用程式，而是在翻閱一卷由抄寫員以墨水寫在羊皮紙上的史書：時間軸是捲起的卷軸，地圖是夾在書頁裡的手繪圖，故事面板是正在閱讀的那一頁。

#### 1.1 三個關鍵字

| 關鍵字 | 在畫面上的意思 |
|---|---|
| 紙 | 大面積是溫暖、低彩度的米黃羊皮紙色；背景由中央向四周微微加深，像紙張邊緣受潮泛黃 |
| 墨 | 文字、線條、地圖輪廓都是深褐墨色，不用純黑；次要資訊用淡墨 |
| 金與鏽 | 少量的褐金與鏽紅只用來標示「被選中」與「值得注意」，是畫面上唯一的強調色 |

#### 1.2 要避免的感覺

- **金屬感**：拉絲金屬、鍍鉻、高光反射、立體斜面按鈕。金色只是墨水般的平塗褐金，不做漸層高光。
- **霓虹感**：發光文字、外光暈（`text-shadow` / `box-shadow` 的彩色光）、高飽和藍紫青。
- **扁平科技感**：純白底、純黑字、無襯線字體、Material 式彩色按鈕、膠囊開關、大面積純色色塊、毛玻璃（`backdrop-filter`）。
- **遊戲 UI 仿冒**：不複製任何官方遊戲的介面框、圖示、字體配置或標誌。本站是同人編年史，要有自己的樣子。
- **過度裝飾**：不加花邊外框、不在每個面板四角放雕花。裝飾只出現在第 4 節列出的位置，其餘地方讓內容說話。

|---|---|---|
| `--ink` | 10.74 : 1 | 任何文字 |
| `--map-stroke` | 7.22 : 1 | 線條、文字 |
| `--rust` | 5.95 : 1 | 連結、小字 |
| `--ink-soft` | 5.43 : 1 | 小字（在 `--parchment-deep` 上降為 4.64 : 1，仍達 AA） |
| `--legend` / `--unresolved` / `--canon` | 5.27 / 4.98 / 4.87 : 1 | 徽章底色配 `--parchment` 小字，達 AA |
| `--gold` / `--disputed` | **2.81 : 1** | **只能用於圖形與粗框，不可當小字的文字色或底色** |

3. 選取狀態不能只靠顏色區分：被選取的事件點同時改變填色與外框；被選取的省份建議除了填色外，也以 `aria-pressed` 或 `aria-current` 告知輔助技術。

### 3. 字型

字型由 Google Fonts 載入（`Base.astro`），`display=swap`。

| 用途 | 英文 | 中文 | 載入字重 |
|---|---|---|---|
| 標題（`h1`–`h3`）、紀元名、日期、地圖區域名、首字放大 | **Cinzel**（`--font-display`） | Noto Serif TC（由字型堆疊自動遞補） | Cinzel 500、700 |

**中文一律 Noto Serif TC。** 中文頁面（`<html lang="zh-Hant-TW">`）的 `body` 改用 `--font-zh`，所以中文內文裡夾雜的英文專有名詞（例如 Tamriel）也以 Noto Serif TC 的拉丁字母顯示，同一行不混兩套內文字體。標題與日期仍用 `--font-display`：其中的拉丁字母與數字由 Cinzel 顯示，中文字由 Noto Serif TC 遞補，這是刻意保留的「碑文感」。Cinzel 與 EB Garamond 都沒有中文字形，不需另外排除。

| 元素 | 英文頁面 | 中文頁面 |
|---|---|---|
| 內文 `body` | 18px，行高 1.6 | **17px，行高 1.8** |
| 頁首標題 `.topbar h1` | 1.4rem | 1.4rem |
| 事件標題 `.story h2` | 1.5rem | 1.5rem |
| 小節標題 `.story h3` | 1rem | 1rem |
| 徽章、頁尾 | 0.75rem | 0.75rem |
| 首字放大 | 2.6em，行高 0.9 | 不使用 |

標題字重 600（Cinzel 會取最接近的 700）；`h1`–`h3` 下方留 0.4em。

#### 3.2 排版規則

- Cinzel 的小寫字母是小型大寫字形，只用在短標題、紀元名與日期，**不用在段落**。
- 中文不用斜體（瀏覽器會用演算法硬把方塊字歪斜，很難看）。英文用斜體的地方（例如 `.story-note`），中文頁面改用 `--ink-soft` 淡墨色與正體字：`html[lang='zh-Hant-TW'] .story-note { font-style: normal; }`。

- 數字與年代（由 `src/lib/format.ts` 產生）：英文頁面 `3E 433`；中文頁面「第三紀元 433 年」，阿拉伯數字前後加半形空白。
- 段落不首行縮排，段與段之間以行距分隔（`margin` 由瀏覽器預設的段落間距提供）。

### 4. 紋理與裝飾

#### 4.1 羊皮紙（第 1 期：純 CSS）

第 1 期不使用任何點陣圖，用漸層模擬羊皮紙：

| 位置 | 做法 |
|---|---|
| 頁面背景 `body` | `radial-gradient(ellipse at center, var(--parchment) 55%, var(--parchment-deep) 100%)`：中央明亮、四周像受潮泛黃 |
| 故事面板 `.story-pane` | 平塗 `--parchment` ＋ `--parchment-edge` 1px 邊框 ＋ `--shadow`，像一張疊在桌上的紙 |
| 時間軸捲面 `.tl-scroll` | 由上到下 `linear-gradient(var(--parchment), var(--parchment-deep))`，上下各 2px `--parchment-edge`，像捲起來的紙面背光處變暗 |
| 地圖 `.map-view` | `--map-sea` 底色 ＋ `inset 0 0 40px` 墨色內陰影，像一張邊緣燒焦的舊地圖 |

```css
body {
  background:
    radial-gradient(ellipse at center, transparent 55%, rgb(201 177 125 / 0.35) 100%),
    url('/assets/parchment-tile.png') repeat var(--parchment);
}
```

（不要用 `background-blend-mode: multiply` 把紋理疊在漸層上：兩層紙色相乘會變成偏橘的深褐色。）

#### 4.2 捲軸軸心

時間軸左右兩端各有一根木製軸心 `.roller`，表示「這是一卷攤開的捲軸」：

- 寬 18px、圓角 9px，上下各凸出捲面 8px。
- 填色為水平木紋漸層 `linear-gradient(90deg, #7a5a35, #c9a066 45%, #6b4a28)`：亮面偏左 45%，表現光從左上方來。
- 帶 `--shadow`，讓軸心浮在紙面上。
- 第 2 期可換成第 6 節 A2 的軸心圖，但尺寸與位置不變。

#### 4.3 首字放大（drop cap）

- 故事正文的第一段第一個字母放大：Cinzel、2.6em、行高 0.9、`--rust` 鏽紅、向左浮動，右側留 6px。
- **只用於英文頁面**（`html[lang='en']`）。中文方塊字等寬排列，首字放大會讓第一、二行的字格對不齊，因此中文頁面不做首字放大，保持整齊的版面。
- 只放大字母，不加裝飾框、不加底圖。

#### 4.4 其他裝飾原則

- 動態只有兩種：手機抽屜高度變化（CSS `transition: height 0.25s ease`），以及時間軸與地圖的平移、縮放（d3 以 JavaScript 驅動，500ms）。
- 使用者開啟「減少動態效果」時：CSS 的部分由 `global.css` 的 `@media (prefers-reduced-motion: reduce) { * { transition: none !important; } }` 取消；**這條規則管不到 JavaScript 動畫**，因此所有 JS 驅動的動畫（d3 transition、`requestAnimationFrame`、Web Animations API）都必須自行檢查 `matchMedia('(prefers-reduced-motion: reduce)').matches`，成立時把時間設為 0，直接跳到結果。計畫中的 Timeline／MapView 以 `duration()` 輔助函式做到這點：`const duration = () => (matchMedia('(prefers-reduced-motion: reduce)').matches ? 0 : 500);`，新的動畫一律沿用。
- 不使用 `text-shadow` 發光；唯一的描邊例外是地圖標記文字用 `--parchment` 3px 描邊（`paint-order: stroke`），讓字壓在地圖線條上仍清楚。
- 分隔線一律 1px `--parchment-edge`，不用雙線或花紋線（第 2 期若要花紋分隔線，列為新的 AIGC 素材）。
