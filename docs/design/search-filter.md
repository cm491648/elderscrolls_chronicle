# 搜尋與篩選｜互動與視覺規格（第 2 期 P2-5 定稿，第 3 期 P3-C 補上篩選項目）

> 使用者決定（2026-10-20，decisions/phase2-search-ui，確認頁 https://claude.ai/artifact/SifRjAmsH9hhfUGzAh6r6W ）：
> - 版面用**甲案**：一個入口按鈕，按了才展開面板。
> - 原話：「功能可先做，但篩選項目先不做，等故事內容夠多之後再來做分類。作品與可信度的篩選確認不會放上，網站定位是有地圖的歷史書，所以跟作品無關；可信度則是玩家自己心中的接受度，不需要網站預先分類」。
>
> 據此：**搜尋**現在完整做；**篩選**只做機制（判斷、變淡、只停在符合的事件、清除、沒有結果的提示），畫面上**不放任何篩選項目**，分類等內容夠多後再和使用者訂；**作品、可信度兩組永遠不做**。沒有篩選項目時，入口按鈕只寫「搜尋」。
> 第 3 期（2026-10-22，decisions/p3-design 與 decisions/p3-retag，確認頁 https://claude.ai/artifact/MAT8zcybVbGkQ9qTk7uttw ）：篩選項目定為**事件類型 7 類**。62 則事件依使用者逐則勾選的結果重新分類（每則類數不設上限）。一度加上遊戲作品 8 款，使用者看過成果後要求移除（2026-10-23，decisions/p3-filter-review：「不需要作品分類，請移除。一些事件難以用作品區分，另外用作品篩選事件也不是網站想要的功能」），所以**作品與可信度的篩選仍然不做**。
>
> 視覺沿用方向 A（`docs/design/style-guide.md`）：方角面板、圖版框（1px 墨框外加金線）、青金石強調、朱紅小標，不用膠囊徽章。

## 1. 搜尋

- 一個 `type="search"` 欄位，邊打字邊列出結果（不必按 Enter），欄位有看得到的標籤（視覺隱藏也可，但要有名稱）。
- 比對範圍：
  - 事件標題（中英文都比對）。
  - 事件標出的人物與術語名稱（中英文都比對）。
  - 正文（只比對頁面語言）。
- 標題與名稱比對時忽略大小寫、重音符號、空白與人名中點（「莫拉格·巴爾」＝「莫拉格巴爾」，`Molag  Bal`＝`molagbal`）。正文只忽略大小寫，這樣片段才能標出命中的字。
- 結果依「標題 > 人物或術語 > 正文」排序，同一級依時間軸順序。每列顯示：
  - 標題與日期。
  - 命中的地方：標題命中不另外註明；名稱命中寫「提到：塔洛斯」；正文命中附命中處前後各約 20 字的片段，關鍵字加粗（切點不會切斷佔兩個 UTF-16 單位的字）。
- 每列是一個連結（`<a href>` 指向事件網址）。一般點擊會選到該事件，網址、地圖、故事都跟著換；窄螢幕同時關閉面板，寬螢幕面板留著。按住修飾鍵點擊則照一般連結處理。
- 搜尋索引 `/<lang>/search.json` 在第一次打開面板時才載入。載入失敗時顯示「無法載入搜尋資料」與「重試」。
- 結果數量用一個 live region 報一次（「找到 3 則」「找不到符合的事件」），不唸整份清單。

## 2. 篩選

- 一組勾選框，在一個 `fieldset`（`legend`「類型」）裡：創世神話 Myth and Creation、神與魔神 Gods and Daedra、戰爭 War、宗教 Religion、災難與瘟疫 Disaster and Plague、遷徙與建國 Migration and Founding、英雄與預言 Heroes and Prophecy（`category_*`）。順序即 `CATEGORIES`。
- `src/lib/filter.ts`：`FilterState = { categories }`。勾任一類即符合（OR）；沒勾等於不限制。
- 不符合的事件在時間軸與地圖上變淡（不消失），仍可點開；上一則／下一則與方向鍵只停在符合的事件。
- 有篩選時，入口按鈕標出勾了幾項，面板底部顯示「符合 7／62 則」與「清除篩選」；沒有符合的事件時顯示「沒有符合篩選的事件。」與「清除篩選」。地圖上一個地點的事件全被篩掉時，標記變淡；地點彈出框裡被篩掉的事件排在後面、變淡。
- 篩選狀態不寫進網址，存在這台裝置的 `localStorage['chronicle.filter']`，重新整理後仍在；清空時刪掉這筆。讀不到或資料不對時當作沒篩選，不認得的項目丟掉（之前存的作品勾選也一併丟掉）。伺服器產生的頁面不帶篩選，頁面活起來後才套用。
- 寬螢幕面板高度不超過地圖，篩選區固定高度，結果清單佔剩下的空間（至少約 8rem），整個面板可以捲動。

## 3. 版面（甲案）

- 頂端列語言切換左邊加入口按鈕（「搜尋與篩選」），`aria-expanded`、`aria-controls`；有篩選時按鈕上標出勾了幾項。
- 寬螢幕（與並排檢視同一條件）：面板疊在地圖左上角、層級路徑下方（「上一層」仍點得到），寬約 360px，高度不超過地圖，自己捲動；圖版框；不推動版面，時間軸與地圖照樣可以操作（非強制的 `role="dialog"`，`aria-modal="false"`）。面板開著時，地圖的「此處事件」彈出框改在右側出現。
- 窄螢幕：全螢幕面板（`aria-modal="true"`，Tab 在面板內循環，底下的頁面設為 `inert`、不捲動），右上「× 關閉」。選了結果後面板關閉，焦點移到故事標題（選的就是目前這則也一樣）。
- 打開時焦點移到搜尋欄位；Esc 或「關閉」關閉面板，焦點回到入口按鈕。面板根元素加 `data-own-arrows`，面板內按方向鍵不切換事件。
- 可點目標至少 24×24px。
